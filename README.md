# Free-Induction-Decay-FID-signal-and-turning-it-into-a-clean-spectrum
Free Induction Decay (FID) signal and turning it into a clean spectrum
This is a short project where i simulate some NMR data of mand FID signals and then train a curvefitting algorithm to try and map the parametes used in the FID to obtian T2 measurements from the outputted signal. 

The plan is to go and train this curve fitting to recognise a specific peak at a position which has a fixed FWHM and then run many random FID and to seperate the ones which have this or may have this. Akin to a pipeline that medical analysis could beenefit from to speed up procdures
